# Mynyra Engine Roadmap

## Completed boundary

- Engine lineage consolidated under `engine/`.
- Broker-neutral safety and accounting foundations implemented.
- cTrader Demo M1 design implemented behind default-off gates.
- Demo milestone operator-accepted on 2026-08-30.
- GitHub governance and protected CI restored for the consolidated layout.

## Current sequence

1. Repository hygiene and authority synchronization.
2. Close static-analysis, dependency, and documentation drift.
3. Onboard Bigi through confirmed identity and task-scoped collaboration.
4. Design a read-only evidence seam only when its provenance, epoch, failure
   state, deployment, authentication, tests, and rollback are approved.
5. Reassess persistence, operational recovery, and qualification gaps before
   any further provider commissioning.

## Explicitly not scheduled

LIVE endpoints/accounts, real-money trading, credential migration, risk-limit
expansion, autonomous provider retries, production deployment, or UI order
controls. Each requires a separate operator-approved plan and evidence gate.
